# TypeScript 計算機

シンプルな TypeScript で実装された計算機能ライブラリです。

## 機能

- 足し算 (`add`)：2つの数値を足し合わせる関数

## 使い方

```typescript
import { add } from './src/calculator';

// 足し算
const sum = add(5, 3); // 8
console.log(sum); // 8
```

## インストール方法

```bash
# パッケージをインストール
npm install

# テストを実行
npm test

# ビルド
npm run build

# プログラムを実行
npm start
```
